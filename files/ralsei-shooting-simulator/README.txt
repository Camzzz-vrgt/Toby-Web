Ralsei Shooting Simulator — HTML version

This folder is the browser build extracted from the supplied Windows game.
It keeps the original GDevelop scenes, artwork, music, and controls.

Play on Windows: double-click Play locally.cmd. Your browser will open the game.
Keep the command window open while playing; close it when finished.

Host online: upload this folder's contents to any static web host, with
index.html at the site root. No server-side code or build step is needed.

Browsers block some assets when index.html is opened directly from a file
location, so use the local launcher or a static web host.
