FNAFtale (William Afton Fight) web runner

Mod page:
https://gamejolt.com/games/fnaftale/1090259

Mod creator: YoshiReal99

This package uses Butterscotch, an open-source Undertale runner licensed under
AGPL-3.0. Source and build instructions:
https://github.com/ButterscotchRunner/Butterscotch

The bundled butterscotch.wasm is a nightly Emscripten build (commit d055268,
"5 args at freddy's") with one local patch: the web runner hardcodes the
framebuffer size to 640x480 in src/web/main.c, which letterboxes this game's
1920x1080 application surface into a corner of the canvas. The six compiled
i32.const 640/480 framebuffer arguments were patched to 1920/1080 so the
surface presents at full size.

The cross-origin isolation helper is coi-serviceworker v0.1.7, licensed under
MIT. Source:
https://github.com/gzuidhof/coi-serviceworker

See LICENSE-BUTTERSCOTCH.txt and LICENSE-COI-SERVICEWORKER.txt.
