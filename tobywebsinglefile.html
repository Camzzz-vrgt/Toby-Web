New Features

  • DR/UT OST Player in Extras — stream the full DELTARUNE and UNDERTALE soundtracks by chapter, with shuffle, repeat, and a "skip last 5 seconds" toggle.
  • Beta Testers section on the Credits page — automatically refreshes Discord role members, display names, and avatars every 10 minutes.
  • tobysingle.html and tobysingle.svg — lightweight fetch-and-run launchers that always pull the newest release.
  • Mobile viewport centering across all game pages — games now stay centered on phones and tablets in both orientations, fixing the URL-bar offset that pushed pages below the visible area.
  • Responsive home page layout — game buttons, stacked presets, and the top-bar controls now adapt properly to small screens.
  • Community theme catalog pagination — themes load in pages as you scroll instead of one giant fetch, with a proper "temporarily unavailable" state.
  • Home button in every game — a small semi-transparent button at the top-left that returns to the site menu.

Bug Fixes

  • Fixed Undertale Magmatomb showing empty dialogue boxes — migrated to the shared butterscotch build that fixes missing text.
  • Fixed C!UNDERTALE missing text the same way.
  • Fixed Starwalker Fight crashing with missing MathUtils errors during battle waves.
  • Fixed Lost Deltarune crashing at the save-select screen, and running at double speed after dying and continuing.
  • Fixed the vanilla Undertale port freezing on boot (missing tick-worker).
  • Fixed browser-storage errors ("Cannot close a ERRORED writable stream") when installing butterscotch ports — it now frees cached game data and retries instead of failing.
  • Fixed butterscotch ports on the single-file launcher — they now open the live-site copy where cross-origin isolation works, instead of showing "The game could not start".

New Features

  • Redesigned mobile controls with automatic touch-device detection, Auto/On/Off modes, and a selectable joystick or arrow-buttons layout.
  • Rebuilt the single-file launcher so it always fetches the newest Toby Web release from GitHub.
  • Added a community Themes page with local theme creation, previews, drafts, ZIP export, installation, a moderated public catalog, and favorites.
  • Added preset button layouts for themes — stack the DELTARUNE and UNDERTALE buttons centered, left, or right.
  • New default theme: "Halloween 2026" — animated background, music, and stacked buttons.
  • Added UNDERTALE Boss Saves — a picker on the Undertale page with 20 preset saves organized by route.
  • Added a Weird Route save option to the Chapter 3 knight-fight modals.
  • Raised theme upload limits to 30 MB backgrounds and 50 MB music.
  • Theme submissions now show a confirmation dialog when they go through.
  • Added a Stats tab on the Themes page — live "who's using what" and all-time leaderboards for every theme.

Bug Fixes

  • Fixed Star Rune crashing with a missing Lua bit-library error on tile maps.
  • Fixed Deep Dreams crashing with "attempt to yield across metamethod/C-call boundary" when a cutscene was stopped from outside a cutscene (hold-skip, map exit, debug console).
  • Fixed Deltarune Frostveil crashing when flipping switches (main-thread coroutine yield when a watcher event stopped the active cutscene).
  • Fixed community-theme styling lingering after switching back to a built-in theme.
  • Reworked theme button positioning into presets — the old free-drag editor was laggy and unreliable.
  • Fixed Pirate Gaster (and other Kristal ports) crashing on bullet-spawn waves like Kirk's "whataboutism" — the engine used a Lua 5.1 implicit vararg table this runtime lacks.
  • Hid Deltarune: Sword Route while a Chapter 1 crash fix is pending.
